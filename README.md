# My Dream Place - Travel Landing Page

A landing page for a travel website. It has a hero with a search bar, destination cards, a "things to do" grid, some stats and a footer. I built it to practice layouts with CSS Grid and Flexbox.

## What's inside

- Sticky header with a menu that opens on mobile
- Hero image with a search bar (the form is only for show, it doesn't search anything yet)
- Destinations, inspiration and popular hotels sections
- "Popular things to do" bento grid
- Responsive layout (mobile, tablet, desktop)

## Built with

- HTML
- CSS (Grid, Flexbox, custom properties, animations)
- A little JavaScript for the mobile menu
- [Lucide](https://lucide.dev) icons

## How to run

No install needed. Download the project and open `index.html` in your browser.
You need internet for the icons and for the banner image near the bottom.
